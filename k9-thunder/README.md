# K9 Thunder 3D — 자주포 정찰·포격 멀티플레이

브라우저에서 바로 하는 K9 자주포 게임. 설치 없음, 링크만 있으면 친구와 같이 플레이.

## 친구와 하기
1. 게임 접속 → 콜사인·팀 선택 → **작전 개시**
2. 상단 **🔗 초대** 버튼 → 링크를 친구에게 전송 (`...?room=방코드`)
3. 친구는 링크 열고 작전 개시만 누르면 같은 방 입장 (같은 팀=협동, 다른 팀=PvP)

## 조작
| 키 | 동작 |
|---|---|
| R / H | 정찰탄 / 고폭탄 선택 |
| Space | 발사 |
| F | 잠긴 표적으로 자동조준 |
| A·D / W·S | 포탑 방위 / 고각 |
| I·K·Q·E | 전진·후진·좌회전·우회전 |
| 1–5 | 장약 |
| V / Tab | 3인칭↔1인칭 / 정찰캠 |

정찰탄을 쏘면 낙하산 카메라가 스스로 회전하며 주변을 스캔하고 적을 자동 식별·잠금합니다.
고폭탄을 쏜 뒤에는 75m 이상 이동해 대포병 사격을 피하세요.

## 기술
- 단일 `index.html` + `vendor/` (three.js r128, mqtt.js 5) — 정적 호스팅(GitHub Pages)만으로 동작
- 멀티: 공개 MQTT 브로커(emqx, hivemq) 2곳을 동시에 WebSocket으로 중계. 먼저 들어온 사람이 AI 봇을 운용(호스트), 나가면 자동 인계
